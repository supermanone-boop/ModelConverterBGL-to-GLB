BGL / glTF → GLB

MSFS ModelLib BGLの埋め込みGLB抽出に加え、通常のglTF・GLBも読み込みます。ZIP内のBIN・DDS・PNG等を参照パスから探し、必要なデータを1つのGLBへまとめます。

1. ファイルを読み込む

空港パッケージZIP / BGL / glTF / GLB

ZIP全体を選択できます。glTFを単独で選ぶ場合は、参照先のBIN・画像ファイルも一緒に選択してください。

ZIPを使わず、フォルダ構成を保ったまま読み込む場合

このツールは index.html 1ファイルで動きます。変換は端末内のブラウザで実行し、モデル・BGL・ZIPはサーバーへ送信しません。大きな空港は空きメモリに注意してください。

2. 検出したモデル

ファイルを選択してください。
まだ解析していません。

端末負荷を避けるため、初期状態では先頭の1モデルだけ選択しています。最初は1つずつ変換し、成功を確認してください。

3. 出力

変換が完了するとGLBまたはZIPの保存リンクが表示されます。

対応形式と限界

  • MSFS 2020/2024 ModelLib BGL: RIFF/GLTF・GLBD内のGLBを抽出し、元のLOD単位でGLB化します。
  • MSFS Scenery BGL: 配置・空港情報だけのBGLにはモデル形状が入っていません。対応するModelLib BGLまたは元のglTF一式が必要です。
  • 通常のglTF 2.0 / GLB 2.0: 外部BIN・画像をまとめてGLB化します。ノード階層・アニメーション・スキン・メッシュは維持します。
  • DDS: DXT1/3/5、ATI1/2、BC4/5、DX10 BC1/2/3/4/5/6H/7に対応。BC6H/BC7はWebGL2またはWASMデコーダーで処理します。WASMの取得にはインターネット接続が必要です。
  • 旧FSX/P3D BGL/MDL: MDL8/MDL9/MDLX/PV系はMSFSのGLTF格納方式とは異なります。形式を検出して診断表示しますが、現在のブラウザ変換エンジンでは未変換です。
  • モデルごとに変換を実行し、1つが失敗しても他のモデルの処理を継続します。失敗理由は診断ログへ出力します。
